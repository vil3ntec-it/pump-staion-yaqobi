# پمپ بنزین — دفترِ حساب‌داریِ پمپ‌بنزین

برنامهٔ ویندوزیِ حساب‌داریِ روزانهٔ یک پمپ‌بنزین: پارچهٔ شیفت‌ها، ورقِ روزانه،
قرض‌داران، گاوصندوق، صرافی، شرکت‌ها، مخزن، مفاد/ضرر و چاپِ همه. بی اینترنت کار
می‌کند؛ با اینترنت اشتراک، همگام‌سازی، پشتیبانِ بیرون و اپِ گوشیِ کارمندان می‌آید.

**برای کی:** صاحبِ پمپ و میرزای شیفت. **پروانه:** اختصاصی (`LICENSE`).

## دانلود

- ویندوز (۶۴ و ۳۲ بیت در یک نصاب): صفحهٔ دانلودِ سایت (`index.html`).
- اپِ کارمندان: اندروید (`PumpYaqobiKar.apk`) و آیفون (افزودنِ `kar/` به صفحهٔ اصلی).

## ساخت و آزمون

```bash
cd native
dotnet build PumpYaqobi.sln -c Release
dotnet test PumpYaqobi.Tests -c Release                              # واحد و رفتاری
dotnet run --project PumpYaqobi.UiTests -c Release -- fullscan        # رابط و کارایی
```

- سنجه‌های زندهٔ برنامه ⇄ پنل ⇄ سرورِ حساب: `tools/live-stack.sh`
- اپِ گوشی: `node tools/check-kar-bot.mjs`
- معماری در دو صفحه: `native/docs/ARCHITECTURE-fa.md`
- قاعده‌هایی که نباید برگردند: `CLAUDE.md`
