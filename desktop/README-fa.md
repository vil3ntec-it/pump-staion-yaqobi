# برنامهٔ کامپیوتری پمپ یعقوبی (نسخهٔ دسکتاپ)

این پوشه، خودِ برنامهٔ پمپ یعقوبی را به یک **برنامهٔ نصب‌شدنی ویندوز** تبدیل می‌کند:

- یک نصب‌کنندهٔ `.exe` با ویزارد نصب — هنگام نصب می‌توانید **درایو و مسیر نصب را انتخاب کنید** (مثلاً `D:\`).
- **صفحهٔ لودینگ (اسپلش)** هنگام باز شدن، مثل نرم‌افزارهای بزرگ.
- اجرای کاملاً **آفلاین و محلی** — بدون نیاز به اینترنت یا سرور.
- ذخیرهٔ داده روی یک **پروتکل امنِ اختصاصی (`app://`)** تا سهمیهٔ ذخیره‌سازی بر اساس فضای دیسک باشد، نه سقف ۵ مگابایتیِ تبِ مرورگر.

> پنلِ «سرور خانگی» (که آدرس و رمزِ سرور را داخل برنامه نشان می‌داد) برداشته شده است.
> راه‌اندازیِ سرورِ خانگی همچنان از پوشهٔ `server/` در ریشهٔ ریپو انجام می‌شود.

## 🔄 آپدیت داخلِ برنامه — بدون نصبِ دوباره

از نسخهٔ ۱٫۱ به بعد، برنامهٔ کامپیوتری خودش نسخهٔ تازهٔ سایت را می‌گیرد:

- هر بار که برنامه باز می‌شود (و بعد هر ۶ ساعت) خودش بررسی می‌کند نسخهٔ تازه‌ای آمده یا نه.
- اگر آمده باشد، پیامی بالای صفحه نشان می‌دهد و در **تنظیمات › ⬇️ آپدیت برنامه** دکمهٔ «آپدیت کن» فعال می‌شود.
- با زدنِ «آپدیت کن» نسخهٔ تازه گرفته می‌شود و با «سوار کردن» همان لحظه اجرا می‌شود — **بدون نصبِ دوباره و بدون از دست رفتنِ داده‌ها**.
- اگر نسخهٔ تازه ناقص یا خراب باشد (اینترنت وسطِ کار قطع شود، برق برود و…)، برنامه **خودکار به نسخهٔ سالمِ قبلی برمی‌گردد** و باز می‌شود.
- دکمهٔ «↩️ برگشت به نسخهٔ همراهِ نصب» هم همیشه در دسترس است.

منبعِ آپدیت به ترتیب: `https://yaqobipump.top/` و بعد `https://vil3ntec-it.github.io/pump-staion-yaqobi/`.
برای منبعِ دیگر (مثلاً سرور خودتان) می‌توانید متغیر محیطی `PUMP_UPDATE_BASE` را تنظیم کنید.

فقط وقتی نصبِ دوباره لازم است که خودِ **پوستهٔ برنامه** (منو، آپدیت‌گر، اجازه‌ها) عوض شود — نه برای تغییرهای خودِ برنامه.

## 🎤 صدا در نسخهٔ کامپیوتری

- **ضبطِ پیام صوتی در چت کار می‌کند** (اجازهٔ مایکروفون در پوسته داده شده است).
- **جستجوی نام با صدا هم کار می‌کند — بدونِ اینترنت و بدونِ هیچ سرور.** برنامه یک موتورِ صدای کوچکِ خودش دارد که تمامش روی همین دستگاه اجرا می‌شود: در صفحهٔ کارمند دکمهٔ 🎓 را بزنید و جلوی هر نام یک‌بار همان نام را بگویید؛ از آن به بعد 🎤 آن نام را می‌شناسد. اگر نشناخت و خودتان روی نام زدید، همان صدا خودکار برای آن نام ثبت می‌شود.
- **پرسیدنِ سوالِ آزاد از ربات با صدا** (جمله‌های آزاد، نه نام) هنوز موتورِ گوگل را لازم دارد و بدونِ اینترنت کار نمی‌کند.

## ⌨️ کلیدهای ویرایش

منوی **ویرایش** (واگرد، بریدن، کپی، چسباندن، انتخاب همه) اضافه شد — پیش از این در نسخهٔ کامپیوتری
`Ctrl+C` و `Ctrl+V` داخلِ کادرها اصلاً کار نمی‌کرد.

## چطور فایل نصب را بگیرم؟

نیازی به کامپیوتر برنامه‌نویس نیست — گیت‌هاب خودش می‌سازد:

1. در گیت‌هاب وارد تب **Actions** شوید.
2. ورک‌فلوی **«ساخت برنامهٔ کامپیوتری (ویندوز)»** را باز کنید و دکمهٔ **Run workflow** را بزنید.
3. چند دقیقه صبر کنید تا سبز شود. سپس فایل نصب در دو جا هست:
   - بخش **Releases** ریپو (نام: «برنامهٔ کامپیوتری پمپ یعقوبی») — فایل `PumpYaqobi-Setup-*.exe`.
   - یا در همان صفحهٔ اجرای ورک‌فلو، بخش **Artifacts**.
4. فایل `.exe` را دانلود و روی ویندوز اجرا کنید. (بار اول ویندوز SmartScreen ممکن است هشدار بدهد چون فایل امضای دیجیتال ندارد — روی «More info → Run anyway» بزنید.)

## ساخت دستی روی کامپیوتر خودتان (اختیاری)

اگر Node.js نصب دارید:

```bash
cd desktop
npm install
npm run dist:win      # نصب‌کنندهٔ ویندوز در پوشهٔ desktop/dist ساخته می‌شود
# یا برای تست سریع بدون ساختِ نصب‌کننده:
npm start
```

## نکته

پوشهٔ `app/` هنگام ساخت به‌صورت خودکار از `index.html` و دارایی‌های ریشهٔ ریپو پر می‌شود
(اسکریپت `scripts/prepare.js`) و در گیت نگه داشته نمی‌شود.
