# پمپ یعقوبی — نسخهٔ Native (C# / .NET)

بازنویسیِ برنامه از HTML به یک نرم‌افزارِ واقعیِ ویندوز.
نسخهٔ HTML **فقط مرجعِ مشخصات** است، نه موتورِ اجرا.

## وضعیتِ فعلی

| لایه | وضعیت | آزموده شده؟ |
|---|---|---|
| `PumpYaqobi.Domain` — موجودیت‌ها و نوع‌های قوی | ✅ کامل | ✅ |
| `PumpYaqobi.Application` — منطقِ مالی | 🟡 قرض‌داران، گاوصندوق، صرافی | ✅ برابریِ عددی با HTML |
| `PumpYaqobi.Persistence` — SQLite + EF Core | ✅ کامل | ✅ روی فایلِ واقعی |
| `PumpYaqobi.Infrastructure` — ابزارِ مهاجرت | ✅ کامل | ✅ با بکاپِ واقعی |
| `PumpYaqobi.Reporting` — PDF بومی | 🟡 صورتِ حسابِ قرض‌دار | ✅ فایلِ واقعی ساخته شد |
| `PumpYaqobi.App` — رابط کاربری Avalonia | ✅ هجده بخش | ✅ عکسِ بی‌نمایشگر از هر بخش |

## رابط کاربری

با Avalonia نوشته شده، نه WPF: روی لینوکس هم ساخته و اجرا می‌شود، پس همین‌جا
هم آزموده می‌شود. `PumpYaqobi.UiTests` پنجرهٔ واقعیِ برنامه را بی‌نمایشگر
می‌سازد و از هر بخش عکس می‌گیرد — چیزی تحویل نمی‌رود که دیده نشده باشد:

```bash
cd native
dotnet run --project PumpYaqobi.UiTests -- shots
```

همان ابزار میانبرهای صفحه‌کلید را هم با کلیدِ واقعی روی همان پنجره می‌آزماید
و اگر بشکنند با کدِ ناصفر بیرون می‌آید.

### اندازه‌ها

اندازهٔ سربرگ، جدول‌ها و کارت‌ها حدس نیست: با `native/tools/measure-site.mjs`
خودِ `index.html` در یک کرومیومِ واقعی باز می‌شود و مقدارِ محاسبه‌شدهٔ مرورگر
خوانده می‌شود. `SiteMetricsTests` همان عددها را قفل می‌کند.

خواندنِ CSS جواب نمی‌دهد: فایل چهار مگابایتی است و هر قاعده چند بار بازنویسی
می‌شود — مثلاً نوشته `.card{border-radius:14px}` ولی مقدارِ واقعی ۱۸ است.

## نسخه

برنامهٔ کامپیوتری از **۳٫۱٫۱** شروع می‌شود. عددها در `native/VERSION` است و
شمارهٔ سوم از شمارهٔ ساختِ ورک‌فلو می‌آید، پس هر انتشار از قبلی بزرگ‌تر است.

⚠️ `RUN_OFFSET` را کم نکنید. نسخه باید همیشه بالا برود؛ اگر نسخهٔ تازه از
نسخهٔ نصب‌شده کوچک‌تر شود، برنامه به‌روزرسانی را **بی‌صدا** رد می‌کند و کاربر
برای همیشه روی نسخهٔ کهنه می‌ماند. `InstallerTests` همین را نگه می‌دارد.

## نصب

انتشار سه فایل دارد و آنی که کاربر می‌خواهد **`PumpYaqobi-Setup.exe`** است:
نصبِ واقعی با آیکونِ دسکتاپ، فهرستِ برنامه‌ها و ثبت در «برنامه‌ها و قابلیت‌ها».

**پوشهٔ نصب را خودِ کاربر انتخاب می‌کند.** پیشنهادِ پیش‌فرض
`%LocalAppData%\Programs\PumpYaqobi` است — همان‌جایی که کروم و وی‌اس‌کد هم
می‌نشینند — چون برنامه خودش را به‌روز می‌کند و فایل‌هایش را جابه‌جا می‌کند و
آن پوشه اجازهٔ مدیر نمی‌خواهد.

اگر کاربر جایی مثلِ `Program Files` را انتخاب کند، جلویش گرفته نمی‌شود؛ ولی:

- نصاب همان‌جا به او می‌گوید که به‌روزرسانی اجازهٔ مدیر خواهد خواست،
- در «تنظیمات › به‌روزرسانی» پوشهٔ نصب و همان یادآوری نشان داده می‌شود،
- و خودِ برنامه هنگامِ به‌روزرسانی **اجازهٔ مدیر می‌گیرد** به‌جای آنکه بی‌صدا
  شکست بخورد. اگر باز هم نشد (کاربر پنجرهٔ اجازه را رد کرد)، دفعهٔ بعد که
  برنامه باز شود همین را می‌گوید — چون بدترین حالت این است که کاربر خیال کند
  به‌روز شده و نشده باشد.

نصبِ دوباره به همان پوشه‌ای می‌رود که بارِ اول انتخاب شده (`UsePreviousAppDir`)،
وگرنه به‌روزرسانی یک نسخهٔ دومِ موازی می‌ساخت.

حساب‌ها در `%AppData%\PumpYaqobi\pump.db` می‌مانند — بیرونِ پوشهٔ نصب، هرجا
که برنامه نصب شده باشد. پس به‌روزرسانی و حتی حذفِ برنامه به آن‌ها دست نمی‌زند.
`InstallerTests` همین را نگه می‌دارد: اگر روزی کسی به نصاب خطی اضافه کند که
آن پوشه را پاک کند، آزمون قرمز می‌شود.

## به‌روزرسانی بدونِ دانلودِ دوباره

بستهٔ کامل ~۵۷ مگابایت است ولی از هر ساخت به ساختِ بعدی معمولاً فقط ~۲ مگابایتش
عوض می‌شود: خودِ فایل‌های برنامه. بقیه — دات‌نت، اِوالونیا، اسکیا — همان‌اند.

پس هر ساخت یک «شناسهٔ پایه» دارد که در `base.id` کنارِ برنامه می‌نشیند و در
نامِ بستهٔ کوچک هم هست. برنامه فقط وقتی بستهٔ کوچک را می‌گیرد که دو شناسه یکی
باشند؛ اگر نسخهٔ کتابخانه‌ها عوض شده باشد خودبه‌خود می‌رود سراغِ بستهٔ کامل.

کاربر هم می‌بیند کدام یک است: «به‌روزرسانیِ کوچک — ۲٫۱ مگابایت» یا
«بستهٔ کامل — ۵۶٫۳ مگابایت».

## اجرای آزمون‌ها

```bash
cd native
dotnet test
```

## چطور درستیِ محاسبات ثابت شده

آزمون‌ها فقط «سلیقهٔ برنامه‌نویس» را نمی‌سنجند. برای هر بخشِ مالی، صدها حالتِ
تصادفیِ قطعی ساخته شد، داخلِ **خودِ `index.html`** در یک کرومیومِ واقعی به
توابعِ اصلیِ برنامه داده شد، و خروجی‌ها در فایل‌های `golden-*.json` ذخیره شدند.
آزمون‌ها همان ورودی‌ها را به C# می‌دهند و عددها را مو‌به‌مو مقایسه می‌کنند.

اگر روزی کسی فرمولی را «بهتر» کند، همان آزمون قرمز می‌شود.
