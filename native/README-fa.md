# پمپ یعقوبی — نسخهٔ Native (C# / .NET)

بازنویسیِ برنامه از HTML به یک نرم‌افزارِ واقعیِ ویندوز.
نسخهٔ HTML **فقط مرجعِ مشخصات** است، نه موتورِ اجرا.

## وضعیتِ فعلی

| لایه | وضعیت | آزموده شده؟ |
|---|---|---|
| `PumpYaqobi.Domain` — موجودیت‌ها و نوع‌های قوی | ✅ کامل | ✅ |
| `PumpYaqobi.Application` — منطقِ مالی | 🟡 قرض‌داران، گاوصندوق، صرافی | ✅ برابریِ عددی با HTML |
| `PumpYaqobi.Persistence` — SQLite + EF Core | ✅ کامل | ✅ روی فایلِ واقعی |
| `PumpYaqobi.Infrastructure` — ابزارِ مهاجرت | ✅ کامل | ✅ با بکاپِ واقعی |
| `PumpYaqobi.Reporting` — PDF بومی | 🟡 صورتِ حسابِ قرض‌دار | ✅ فایلِ واقعی ساخته شد |
| `PumpYaqobi.App` — رابط کاربری Avalonia | ✅ هجده بخش | ✅ عکسِ بی‌نمایشگر از هر بخش |

## رابط کاربری

با Avalonia نوشته شده، نه WPF: روی لینوکس هم ساخته و اجرا می‌شود، پس همین‌جا
هم آزموده می‌شود. `PumpYaqobi.UiTests` پنجرهٔ واقعیِ برنامه را بی‌نمایشگر
می‌سازد و از هر بخش عکس می‌گیرد — چیزی تحویل نمی‌رود که دیده نشده باشد:

```bash
cd native
dotnet run --project PumpYaqobi.UiTests -- shots
```

همان ابزار میانبرهای صفحه‌کلید را هم با کلیدِ واقعی روی همان پنجره می‌آزماید
و اگر بشکنند با کدِ ناصفر بیرون می‌آید.

### اندازه‌ها

اندازهٔ سربرگ، جدول‌ها و کارت‌ها حدس نیست: با `native/tools/measure-site.mjs`
خودِ `index.html` در یک کرومیومِ واقعی باز می‌شود و مقدارِ محاسبه‌شدهٔ مرورگر
خوانده می‌شود. `SiteMetricsTests` همان عددها را قفل می‌کند.

خواندنِ CSS جواب نمی‌دهد: فایل چهار مگابایتی است و هر قاعده چند بار بازنویسی
می‌شود — مثلاً نوشته `.card{border-radius:14px}` ولی مقدارِ واقعی ۱۸ است.

## نصب

انتشار سه فایل دارد و آنی که کاربر می‌خواهد **`PumpYaqobi-Setup.exe`** است:
نصبِ واقعی با آیکونِ دسکتاپ، فهرستِ برنامه‌ها و ثبت در «برنامه‌ها و قابلیت‌ها».

نصب **برای همین کاربر** است و در `%LocalAppData%\Programs\PumpYaqobi`
می‌نشیند — نه در `Program Files`. دلیلش این است که برنامه خودش را به‌روز
می‌کند و فایل‌هایش را جابه‌جا می‌کند؛ داخلِ `Program Files` این کار هر بار
اجازهٔ مدیر می‌خواهد و به‌روزرسانیِ خودکار عملاً می‌میرد. همان کاری که کروم و
وی‌اس‌کد می‌کنند.

حساب‌ها در `%AppData%\PumpYaqobi\pump.db` می‌مانند — بیرونِ پوشهٔ نصب. پس
به‌روزرسانی و حتی حذفِ برنامه به آن‌ها دست نمی‌زند. `InstallerTests` همین را
نگه می‌دارد: اگر روزی کسی به نصاب خطی اضافه کند که آن پوشه را پاک کند،
آزمون قرمز می‌شود.

## اجرای آزمون‌ها

```bash
cd native
dotnet test
```

## چطور درستیِ محاسبات ثابت شده

آزمون‌ها فقط «سلیقهٔ برنامه‌نویس» را نمی‌سنجند. برای هر بخشِ مالی، صدها حالتِ
تصادفیِ قطعی ساخته شد، داخلِ **خودِ `index.html`** در یک کرومیومِ واقعی به
توابعِ اصلیِ برنامه داده شد، و خروجی‌ها در فایل‌های `golden-*.json` ذخیره شدند.
آزمون‌ها همان ورودی‌ها را به C# می‌دهند و عددها را مو‌به‌مو مقایسه می‌کنند.

اگر روزی کسی فرمولی را «بهتر» کند، همان آزمون قرمز می‌شود.
