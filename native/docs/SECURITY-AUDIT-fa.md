# ممیزیِ امنیتیِ برنامهٔ کامپیوتر (Client) — ۱۴۰۵/۰۷/۱۲ (نسخهٔ 3.1.161)

سمتِ سرور جداست: `vil3ntec-it/shop` ⇒ `docs/SECURITY-AUDIT-fa.md` (سرورِ حساب)
و `vil3ntec-it/server` ⇒ `docs/SECURITY-AUDIT-fa.md` (سرورِ خانگی).

قاعده‌هایی که کلِ این کار روی آن‌ها بند است:

- ⛔ **هیچ کلیدِ خصوصی و هیچ رازی داخلِ برنامه نیست.** برنامه فقط کلیدِ
  **عمومی** دارد (سنجیدنِ امضا)؛ امضا کردن فقط روی سرورِ حساب است.
- ⛔ **پنهان‌کاری امنیت نیست.** قفلِ واقعی امضای ES256 است و سنجشِ سرور؛ هر
  چیزی که روی دیسکِ کاربر است قابلِ دست‌کاری فرض شده.
- ⛔ **هیچ تصمیمِ امنیتیِ مهم فقط با برنامه نیست**: پشتیبانِ ابری، عکسِ زنده و
  کیو‌آرِ زنده هر بار روی سرور سنجیده می‌شوند؛ برنامه فقط تصمیمِ آفلاین را
  می‌گیرد و آن هم فقط از روی مجوزِ امضاشده.

## B) معماری — کجا چه چیزی تصمیم گرفته می‌شود

```
LicenseGuard.Check / CheckStored   ⇐ تنها جای سنجشِ مجوز (امضا ← هویت ← زمان)
LicenseClock                       ⇐ تنها جای «اکنون» برای مجوز
Entitlements.State / Allows        ⇐ تنها جای «باز/بسته»
CloudLink.AdoptLicense             ⇐ تنها درِ نشستنِ مجوزِ تازه
CloudLink.AccountAsync             ⇐ تنها راهِ درخواست با توکنِ حساب (یک قفلِ سراسری)
CloudLink.DevSendAsync             ⇐ تنها راهِ درخواست با توکنِ دستگاه
SecretStore                        ⇐ تنها جای رازها روی دیسک (DPAPI / AES-GCM)
SafeOpen · ErrorText               ⇐ تنها راهِ «باز کن» و تنها راهِ متنِ خطا
UpdateService                      ⇐ میزبانِ مجاز + SHA256SUMS + امضای اختیاری
```

ترتیبِ قیدهای `LicenseGuard` مهم است و عوض نمی‌شود: **اول امضا**، بعد `aud`،
`duid`، `stn`، اثرِ انگشتِ کامپیوتر، و آخر `nbf`/`exp` با ساعتِ `LicenseClock`.

## C) جریانِ آنلاین

```
ورود (ایمیل/رمز یا کدِ ایمیلی) ⇒ توکنِ حساب (یک ساعت) + تازه‌سازی (۹۰ روز، چرخشی)
  ⇒ /api/pump/me ⇒ bind (فقط صاحب/مدیرِ پمپ) ⇒ توکنِ دستگاه + کلیدِ عمومی
  ⇒ device/license ⇒ AdoptLicense (امضا و هویت پیش از نشستن)
حلقهٔ ۶۰ ثانیه‌ای ⇒ KeepLicenseFreshAsync: ناجوریِ «سرور می‌گوید» با «مجوز می‌گوید»
  یا هر ده دقیقه ⇒ مجوزِ تازه. مجوزِ خالی ⇒ مجوزِ کهنه پاک.
```

## D) جریانِ آفلاین

```
مجوزِ روی دیسک ⇒ CheckStored:
   امضا نمی‌خورد      ⇒ هیچ قابلیتی (دفتر همچنان باز)
   سالم و زنده        ⇒ فهرستِ feat
   سالم و منقضی       ⇒ تا exp+14 روز همان فهرستِ feat (ارفاق)، بعد بسته
   ساعت عقب رفته      ⇒ «اکنون» = کفِ ساعت؛ پیامِ «ساعتِ این کامپیوتر عقب است»
   کامپیوترِ دیگر     ⇒ نامعتبر؛ «دوباره وارد شوید»؛ هیچ داده‌ای پاک نمی‌شود
```

⛔ **دفترِ خودِ کاربر هیچ‌وقت قفل نمی‌شود** — دیدن، چاپ، بک‌آپ و بازگردانیِ محلی
و پشتیبانی همیشه بازند (`LicenseGuard.Allows` برای `core`). و امروز
`Entitlements.UnlockedForNow = true` است، پس هیچ‌کدامِ این قیدها قفلی را
نمی‌بندد تا صاحب ریپو بگوید.

## E) مدلِ تهدید

| مهاجم | چه می‌تواند | چه نمی‌تواند |
|---|---|---|
| کاربرِ همان کامپیوتر | فایل‌ها را بخواند و عوض کند، ساعت را عقب ببرد | مجوز امضا کند (کلیدِ خصوصی نیست)؛ با ساعت یا کپیِ تنظیمات قفل را دور بزند |
| کپیِ پوشه به کامپیوترِ دیگر | دفتر را بخواند (رمزنگاری‌نشده، عمداً) | اشتراک را با خودش ببرد |
| شبکهٔ پمپ (LAN) | خود را سرورِ خانگی جا بزند (M2، باز) | توکنِ حساب یا مجوز بگیرد |
| مردِ میانی با گواهیِ ریشهٔ جعلی | پاسخِ بی‌امضای `/me` را عوض کند | مجوز بسازد؛ ارفاق را جلو ببرد (F9 بسته شد) |
| سرورِ ساختگی | — | با کلیدِ دیگر مجوز بدهد (`key_mismatch`) |
| بستهٔ به‌روزرسانیِ دست‌خورده | — | نصب شود (هش و میزبان سنجیده می‌شوند) |

## F) چه چیزی کجای دیسک است

| داده | جا | حفاظت |
|---|---|---|
| توکنِ حساب، تازه‌سازی، توکنِ دستگاه، رمزِ نوشتنِ سرورِ خانگی | `settings.json` | `SecretStore` (DPAPI روی ویندوز، AES-GCM جای دیگر) |
| مجوزِ امضاشده | `settings.json` | لازم نیست — امضا دارد |
| کلیدِ عمومی | ساخت (`LicenseKeys`) یا `settings.json` (TOFU، وقتی ساخت خالی است) | عمومی است |
| رمزِ برنامه و رمزِ بخش‌ها | `pump.db` | فقط `pbkdf2$sha256$…`، هیچ‌وقت خام |
| دفتر | `%AppData%\PumpYaqobi\pump.db` | رمزنگاری‌نشده (عمداً — بی‌اینترنت و بی‌کلید باید باز شود) |
| متنِ خامِ خطا | `crash.log` | فقط محلی |

⛔ رمزِ گذرِ ابر هیچ‌جا روی دیسک نیست؛ هیچ توکنی در لاگ نیست.

## H) تغییرهای خطرناک — و چرا لازم بودند

- **ارفاق فقط از مجوز**: کسی که امروز فقط مُهرِ ارفاق دارد و هیچ مجوزِ سالمی
  ندارد، روزِ قفل کردن ارفاق نمی‌گیرد. لازم بود چون همان مُهر با یک ویرایشِ
  JSON هر شش قفل را برای همیشه باز می‌کرد. امروز بی‌اثر است (`UnlockedForNow`).
- **`SHA256SUMS.txt` اجباری**: نسخه‌ای که این فایل را نداشته باشد نصب نمی‌شود.
  هر دو درِ انتشار (`releases/latest` و `desktop-latest`) از قبل این فایل را
  دارند (سنجیده شد).
- **`LicenseKeys`**: تا متغیرِ `LICENSE_PUBLIC_KEYS` در مخزن خالی است، رفتار همان
  TOFUِ دیروز است. پر کردنش پیش از آن‌که سرورِ حساب همان `kid` را بفرستد یعنی
  `key_mismatch` برای همه — پس ترتیب: اول کلیدِ **فعلیِ** سرور را با `kid`ش در
  متغیر بگذارید، بعد انتشار.
- **امضای به‌روزرسانی**: `UPDATE_PUBLIC_KEY` را فقط وقتی بگذارید که رازِ
  `UPDATE_SIGNING_KEY` هم هست؛ وگرنه نسخهٔ منتشرشده امضا ندارد و برنامه نصبش
  نمی‌کند (ورک‌فلو همین را هشدار می‌دهد).
