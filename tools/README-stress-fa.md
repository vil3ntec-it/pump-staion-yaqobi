# آزمونِ نشستِ طولانی

این دو ابزار برای پیدا کردنِ «برنامه بعد از مدتی یخ می‌زند / صفحه ناپدید می‌شود»
ساخته شده‌اند. هیچ‌کدام به کدِ برنامه دست نمی‌زنند — فقط برنامه را در یک مرورگرِ
واقعی می‌رانند و اندازه می‌گیرند.

## چه چیزی اندازه می‌گیرند

| معیار | یعنی چه |
|---|---|
| `heapMB` | حافظهٔ زندهٔ جاوااسکریپت (بعد از سه بار جمع‌آوریِ زباله) |
| `nodes` | تعدادِ گره‌های DOM — اگر مدام بالا برود یعنی گره‌های جدا افتاده انباشته می‌شوند |
| `liveListeners` | شنونده‌های **زندهٔ** رویداد (شمارشِ خودِ کروم، نه ثبت‌ها) |
| `intervals` / `timeouts` | تایمرهای پاک‌نشده |
| پاسخ‌دهی | چند میلی‌ثانیه طول می‌کشد تا نخِ اصلی به یک کارِ کوچک برسد — «فریز» یعنی این عدد بالا برود |

> ⚠️ `liveListeners` را با شمارشِ دستیِ `addEventListener` اشتباه نگیرید. کارتی
> که هر بار از نو ساخته می‌شود، هر بار شنونده می‌گیرد؛ این «نشت» نیست چون خودِ
> کارت دور انداخته می‌شود. تنها عددی که نشت را نشان می‌دهد همین `liveListeners`
> است.

## اجرا

نیاز به `playwright-core` و یک کرومیوم دارد (روی این مخزن نصب نیست):

```bash
ROUNDS=60 node tools/stress-session.mjs        # ناوبری، مودال، ربات، تم
ROUNDS=40 node tools/stress-sync.mjs           # + سرورِ خانگیِ واقعی و عکس‌های پیاپی
```

- `PW_CHROMIUM` — مسیرِ کرومیوم، اگر playwright خودش پیدایش نکرد
- `HLP_SERVER_ENTRY` — مسیرِ `src/index.js`ِ مخزنِ `server` (برای `stress-sync`)

همان لحظه را به این اسکریپت‌ها اضافه کنید تا بازتولید شود.
